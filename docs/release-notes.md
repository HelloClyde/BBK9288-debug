# 9288 Debug v0.2.1（实验预发布）

- 解决前台游戏持续运算时 COM 口仍能枚举、调试请求却超时的问题。驻留 USB 任务从优先级 7 调整到 5，高于已验证固件上的 GUI1（优先级 6），每批处理后继续主动让出 CPU。
- 本地机端构建和公开发布统一使用 D88DEBUG 专用终端图标。

真机上用《黑神话》验证了前台运算期间的状态查询、程序内存读取和截图。真机测试构建和本包载荷的对应关系见[验证记录](https://github.com/HelloClyde/BBK9288-debug/blob/v0.2.1/docs/validation.md)。

下载 Windows ZIP。用 `device/系统/程序/9288Debug.exe` 替换机端文件，正常重启 9288，再从「工具」中启动 D88DEBUG。Windows 客户端位于 `pc`，可继续使用已有客户端。本版本适用于验证过的原版 9288 V1.3 固件。
