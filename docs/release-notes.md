# 9288 Debug v0.1.0（实验预发布）

首次独立开源发布，源码采用 GPL-3.0-only。包含原版 9288 的堆驻留 USB CDC 服务与 Windows 图形客户端，支持 320×240 截图、单次原生 GUI 按键、受限 RAM 检查、带 CRC/回读校验的文件传输，以及调试期间的自动关机保活。

推荐下载 `BBK9288-debug-0.1.0-windows-x64.zip`。解压后把 `device/系统/程序/9288Debug.exe` 复制到设备卷的 `系统/程序`；电脑运行 `pc/9288Debug-PC.exe`。USB 线可一直插着供电，但启动前必须在机端退出 USB 磁盘界面。运行 D88DEBUG 至 READY 后返回菜单，再连接调试串口。更新驻留构建前需正常重启设备。

仅适用于已匹配 `CAPTURED-0215EBC4` 固件配置的**原版 9288**，不支持 9288T、9288S、H1 或 9588；不匹配的配置会被拒绝。按键通过原生 GUI 排队，不能控制所有直接轮询键盘矩阵的游戏。目录浏览、任意 RAM 写入及任意代码执行不在本版能力内。

设备核心保持已验证的 `image_id=f9dc2295`；新容器使用可再生图标，实际载荷 SHA-256 与历史真机版本完全相同。历史版本通过五次普通重连、20 KiB 文件传输/替换/取消、同名保护及 GUI 左右键，最终 1294 次请求、0 错误。新图标容器未另做真机运行，当前构建的 STOP/磁盘恢复及长期关机恢复仍需补测。主机测试、实际 S1C33 编译、重定位、冻结界面启动和安装包完整性由本次 Actions 验证；具体范围见源码中的 `docs/validation.md` 和资产 `build-report.json`。

本 Release 不含原厂固件、NAND、SDK、工具链或用户数据。`SHA256SUMS.txt` 覆盖其余四个交付文件；安装 ZIP 内另有逐文件清单与第三方许可证。
